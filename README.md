# EVLV Fitness — Proof of Trading & Corporate Website

A clean, barebones Next.js + Tailwind CSS website presenting **EVLV Fitness**, its scope of trading, and corporate verification details for company checks, payment processing due diligence, and regulatory records.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

Install dependencies:
```bash
pnpm install
# or npm install
```

Run development server:
```bash
pnpm dev
# or npm run dev
```

Open [http://localhost:3010](http://localhost:3010) with your browser.

## Placeholders to Update
In `src/app/page.tsx`:
- Company / Registration Number (e.g. Companies House number)
- Registered Office Address
- Principal Place of Business / Trading Address
- Official Email (`contact@evlvfitness.com`)
